# SEL Measurement Tools

## Overview

Measuring social-emotional learning (SEL) in the FG2G curriculum requires tools that are sensitive to trauma, culturally responsive, and developmentally appropriate. The FG2G SEL measurement system does not reduce students to single scores or labels. Instead, it captures patterns of growth across multiple competency areas, always contextualizing data within the student's regulation history and lived experience.

All SEL measurement in FG2G aligns with the CASEL (Collaborative for Academic, Social, and Emotional Learning) framework's five core competency areas while adding trauma-specific indicators unique to this curriculum.

## Connection to CASEL Competencies

| CASEL Competency | FG2G Alignment | Primary 5Rs Phase | Garden Context |
|-----------------|---------------|-------------------|----------------|
| **Self-Awareness** | Regulation self-assessment; growth mindset reflection | Root, Regulate | Noticing body cues during garden work; identifying emotions connected to garden experiences |
| **Self-Management** | Regulation strategy use; sustained task engagement | Regulate, Restore | Using garden tasks for regulation; persisting through challenging garden problems |
| **Social Awareness** | Perspective-taking; cultural appreciation; empathy | Reflect, Reconnect | Understanding diverse food traditions; considering community needs in harvest planning |
| **Relationship Skills** | Collaborative garden work; peer teaching; conflict resolution | Reconnect | Working in garden teams; sharing resources; mentoring younger students |
| **Responsible Decision-Making** | TRACE protocol application; ethical garden practices | Restore, Reconnect | Making sustainable choices in the garden; deciding how to distribute harvest equitably |

## Tool 1: Self-Regulation Assessment Scale (SRAS)

### Purpose

The SRAS measures a student's developing capacity for self-regulation across four domains: emotional regulation, behavioral regulation, cognitive regulation, and sensory regulation.

### Administration

- **Who administers**: Educator completes based on observation; student completes self-report version (grades 3+)
- **Frequency**: Monthly
- **Duration**: 5 minutes per student (educator); 10 minutes (student self-report)

### Scale Items

| Domain | Indicator | Never (1) | Rarely (2) | Sometimes (3) | Often (4) | Consistently (5) |
|--------|-----------|-----------|-----------|---------------|-----------|-------------------|
| **Emotional** | Identifies own emotions accurately | | | | | |
| **Emotional** | Uses a calming strategy when upset | | | | | |
| **Emotional** | Recovers from frustration within a reasonable time | | | | | |
| **Behavioral** | Follows garden routines without reminders | | | | | |
| **Behavioral** | Transitions between activities smoothly | | | | | |
| **Behavioral** | Manages impulses during group work | | | | | |
| **Cognitive** | Sustains attention during garden observation tasks | | | | | |
| **Cognitive** | Plans steps before beginning a garden task | | | | | |
| **Cognitive** | Shifts thinking when a strategy is not working | | | | | |
| **Sensory** | Tolerates varied sensory input in the garden (soil, smells, sounds) | | | | | |
| **Sensory** | Seeks appropriate sensory input when dysregulated | | | | | |
| **Sensory** | Modulates sensory responses in different environments | | | | | |

### Scoring and Interpretation

- **Domain scores**: Average the items within each domain (range 1-5).
- **Total SRAS score**: Average all domain scores (range 1-5).
- **Growth interpretation**: A 0.5-point increase in any domain score across a quarter indicates meaningful progress.
- **Profile analysis**: Compare domain scores to identify relative strengths and growth areas. For example, a student with strong emotional regulation but weaker cognitive regulation may benefit from TRACE protocol scaffolding.

## Tool 2: Social Skills Observation Tool (SSOT)

### Purpose

The SSOT captures observable social behaviors during collaborative garden activities, providing data on relationship skills and social awareness.

### Observation Protocol

Educators observe students during collaborative garden tasks (e.g., partner planting, team harvest, group design projects) using a structured observation form.

| Social Skill Category | Observable Behaviors | Observed (check) | Notes |
|----------------------|---------------------|-------------------|-------|
| **Communication** | Uses respectful tone; listens without interrupting; asks clarifying questions | | |
| **Cooperation** | Shares materials; takes turns; contributes to group goals | | |
| **Conflict Resolution** | Expresses disagreement respectfully; proposes solutions; accepts compromise | | |
| **Empathy** | Acknowledges others' feelings; offers help; adjusts behavior based on others' needs | | |
| **Leadership** | Organizes group work; encourages peers; delegates tasks fairly | | |
| **Inclusivity** | Invites others to participate; values diverse contributions; avoids exclusionary behavior | | |

### Rating Scale

After observation, educators rate each category:

| Rating | Description |
|--------|-------------|
| **1 - Not Yet Evident** | Behavior not observed; student may need explicit instruction in this skill |
| **2 - Emerging** | Behavior observed inconsistently or only with significant adult support |
| **3 - Developing** | Behavior observed in some contexts; student can demonstrate with minimal prompting |
| **4 - Consistent** | Behavior observed reliably across garden contexts; student demonstrates independently |
| **5 - Modeling** | Student consistently demonstrates the skill and supports peers in developing it |

### Frequency

- Full SSOT observation: Monthly (rotate focus students so each student is formally observed at least once per month)
- Brief anecdotal social skill notes: Ongoing during collaborative garden work

## Tool 3: Growth Mindset Survey

### Purpose

This survey measures students' beliefs about intelligence, effort, and learning, tracking the development of growth mindset over time.

### Administration

- **Grades K-2**: Administered orally with picture supports; educator records responses
- **Grades 3-12**: Written self-report; can be administered digitally
- **Frequency**: Three times per year (fall, winter, spring)

### Survey Items (Grades 3-12 Version)

Students respond on a scale: Strongly Disagree (1), Disagree (2), Neutral (3), Agree (4), Strongly Agree (5).

| Item | Growth Mindset Direction |
|------|------------------------|
| 1. When a garden experiment fails, it means I can learn something new. | Agree = growth |
| 2. Some people are naturally good at gardening and some are not. | Disagree = growth |
| 3. I can get better at reasoning if I practice. | Agree = growth |
| 4. Making mistakes in the garden helps me understand plants better. | Agree = growth |
| 5. If I struggle with a garden task, it means the task is too hard for me. | Disagree = growth |
| 6. I can improve my regulation skills with practice and support. | Agree = growth |
| 7. When I use the TRACE protocol, my thinking gets stronger. | Agree = growth |
| 8. Smart people do not have to try hard. | Disagree = growth |
| 9. I like garden challenges that make me think hard. | Agree = growth |
| 10. My effort matters more than my natural ability. | Agree = growth |

### Scoring

- Reverse-score items 2, 5, and 8.
- Calculate total score (range 10-50).
- Growth mindset range: 40-50 (strong), 30-39 (developing), 20-29 (mixed), 10-19 (fixed mindset predominant).

## Tool 4: Resilience Indicators Checklist

### Purpose

This tool tracks observable indicators of resilience -- the capacity to adapt and recover from adversity -- within the garden learning context. It is particularly important for students who have experienced trauma.

### Indicators

| Resilience Domain | Indicator | Beginning of Year | Mid-Year | End of Year |
|------------------|-----------|-------------------|----------|-------------|
| **Perseverance** | Continues working on a difficult garden task after initial frustration | | | |
| **Perseverance** | Returns to a task after a break rather than abandoning it | | | |
| **Adaptability** | Adjusts plan when garden conditions change (weather, pests, unexpected results) | | | |
| **Adaptability** | Tries a new strategy when the first approach does not work | | | |
| **Help-Seeking** | Asks for help from a peer or adult when stuck | | | |
| **Help-Seeking** | Accepts help without shame or resistance | | | |
| **Optimism** | Expresses hope about future garden outcomes despite current setbacks | | | |
| **Optimism** | Identifies something positive in a challenging garden experience | | | |
| **Connection** | Maintains positive relationships with garden partners during stress | | | |
| **Connection** | Contributes to community garden events even during difficult personal periods | | | |

### Rating Scale

Each indicator is rated: Not Yet (0), Emerging (1), Developing (2), Consistent (3).

## Tool 5: Regulation Progression Tracking

### Purpose

This tool maps each student's movement through a developmental progression of regulation capacity over the course of the year.

### Regulation Progression Stages

| Stage | Description | Typical Indicators | Garden Evidence | Approximate Timeline |
|-------|------------|-------------------|-----------------|---------------------|
| **1: External Regulation** | Student depends on adult co-regulation; cannot self-regulate independently | Requires adult proximity to remain calm; needs moment-by-moment guidance; cannot identify own regulation state | Cannot engage in garden tasks without direct adult support; may refuse or flee garden space | Entry point for many trauma-affected students |
| **2: Supported Regulation** | Student begins to use regulation strategies with adult prompting | Responds to adult cues ("Remember your breathing"); can use one strategy with reminders; beginning to identify regulation level on scale | Engages in simple garden tasks (watering, sorting) with adult nearby; uses garden regulation station with prompting | Weeks 4-8 of implementation |
| **3: Emerging Self-Regulation** | Student initiates regulation strategies with decreasing adult support | Independently moves to regulation station sometimes; can name current regulation level; uses 1-2 strategies without prompting | Chooses garden regulation tasks independently; sustains garden work for 10-15 minutes; recovers from minor frustration | Weeks 8-16 |
| **4: Developing Self-Regulation** | Student reliably self-regulates in familiar contexts | Consistently uses regulation strategies in the garden; can articulate what helps; monitors own regulation level | Sustains complex garden tasks for 20+ minutes; manages transitions; participates in collaborative garden work | Months 4-6 |
| **5: Flexible Self-Regulation** | Student self-regulates across contexts and supports peers | Transfers regulation skills to new settings; adapts strategies to different situations; co-regulates with peers | Independently manages garden challenges; mentors younger students; leads regulation activities | Months 6-12+ |

### Tracking Method

Educators record the student's current stage monthly. Movement between stages is not expected to be linear -- students may move between adjacent stages depending on external stressors, and this is normal and expected.

## Data Integration and Reporting

### Comprehensive SEL Profile

At the end of each quarter, data from all five SEL measurement tools is compiled into a Comprehensive SEL Profile for each student.

| Profile Section | Data Sources | Format |
|----------------|-------------|--------|
| Regulation summary | SRAS scores; regulation progression stage; daily check-in trends | Narrative with trend graph |
| Social skills summary | SSOT ratings; collaborative project observations | Strengths list with growth areas |
| Mindset development | Growth mindset survey scores across administrations | Score comparison (fall/winter/spring) |
| Resilience indicators | Resilience checklist ratings across administrations | Progress chart showing indicator growth |
| Overall SEL narrative | All tools integrated | 2-3 paragraph summary written by educator |

### Trauma-Sensitive Reporting Practices

- SEL data is never used to label, track, or sort students into fixed categories.
- Reports emphasize growth trajectories rather than single-point scores.
- Language is always strength-based: "developing capacity for..." rather than "unable to..."
- SEL data is shared with families in the context of the portfolio conference, not as isolated scores.
- Data is stored securely and accessed only by authorized educators and support staff.

## Implementation Guidance

### Sequencing SEL Measurement Introduction

| Timeline | Tool to Introduce | Rationale |
|----------|-------------------|-----------|
| **Week 1-4** | Daily regulation check-in (simplified version of SRAS) | Establish regulation monitoring as a routine before adding complexity |
| **Month 2** | SSOT (begin informal observations) | Collaborative garden work has begun; social behaviors are observable |
| **Month 3** | Full SRAS; Growth Mindset Survey (first administration) | Students are familiar with regulation language and garden routines |
| **Month 4** | Resilience Indicators Checklist | Enough time has passed to observe resilience patterns |
| **Month 5** | Regulation Progression Tracking (assign initial stages) | Sufficient data exists to accurately place students on the progression |

### Training Requirements

Educators administering SEL measurement tools must complete the following professional development:

1. Module 1: Understanding ACEs and trauma (see Professional Development section)
2. Module 2: The 5Rs Framework
3. SEL measurement training workshop (3 hours): Tool administration, scoring, and interpretation
4. Ongoing calibration sessions: Quarterly team scoring sessions to ensure inter-rater reliability on observation tools
