# Appendix E: Error Analysis Framework and Templates

## Overview

The Error Analysis Framework is used during the Restore phase to systematically analyze errors, reframe them as learning opportunities, and build growth mindset. This appendix provides the classification system, analysis templates, and educator scripts for each grade band.

## Error Classification System

### The Five Error Types

| Error Type | Definition | Example | Restore Response |
|-----------|-----------|---------|-----------------|
| **Computational** | Arithmetic or calculation mistake; the procedure was correct but a number was wrong | 7 x 8 = 54 (instead of 56) | "Your strategy was right! Let's just double-check this calculation." |
| **Procedural** | Steps performed in wrong order or a step was skipped | Measuring plant height before zeroing the ruler | "You know the steps -- let's walk through the order together." |
| **Conceptual** | Misunderstanding of the underlying concept | Believing all seeds need the same amount of water | "Interesting thinking. Let's look at this idea more closely." |
| **Strategic** | Chose an approach that doesn't fit the problem | Using addition when the problem requires multiplication | "You tried a strategy -- let's think about whether it's the best fit for this type of problem." |
| **Reading/Interpretation** | Misread the problem, data, or instructions | Reading a thermometer incorrectly; misunderstanding a word problem | "Let's re-read this together slowly. What is it actually asking?" |

## The Restore Phase Process

### Step 1: Acknowledge and Reframe

**Never say**: "That's wrong." / "No." / "Try again."

**Instead say**:

| Grade Band | Language Model |
|-----------|---------------|
| **K-2** | "Oops! That's an oops-and-grow moment. Your brain is learning something new right now!" |
| **3-5** | "Interesting! Your brain just hit a bump. That means new connections are forming. Let's figure out what happened." |
| **6-8** | "Good -- you found an error. That's actually valuable information. Let's analyze it." |
| **9-12** | "This is worth investigating. Where did your reasoning diverge? Let's trace it back." |

### Step 2: Locate the Divergence Point

Work with the student to identify exactly where the error occurred:

- "Walk me through what you did, step by step."
- "At which point did things start to go differently than expected?"
- "Let's compare your work to this correct example. Where do they start to differ?"

### Step 3: Classify the Error

Help the student identify the error type:

- "Was it a calculation issue, or did you understand the concept differently?"
- "Did you skip a step, or was your approach different?"
- "Did you read the problem the way it was intended?"

### Step 4: Self-Correct

Guide the student to correct the error themselves:

- "Now that you can see where it happened, can you fix it?"
- "What would you do differently if you started over?"
- "How would you check to make sure the new answer is right?" (Connect to TRACE Check step)

### Step 5: Consolidate

Reinforce the learning:

- "What did your brain just learn from that error?"
- "How will you watch for that kind of error next time?"
- "That error taught you something important. Let's write it in your growth journal."

## Error Analysis Templates

### K-2: Oops and Grow Sheet

```
My Oops-and-Grow Moment

What I was trying to do: _______________
What happened: ________________________
What my brain learned: _________________
[Draw a picture of your brain growing!]
```

### 3-5: Error Detective Sheet

```
Error Detective Report

Problem/Activity: _____________________
What I did: ___________________________
Where the error happened: ______________
Type of error:  [ ] Calculation  [ ] Steps  [ ] Understanding
                [ ] Strategy    [ ] Reading
What I learned: _______________________
What I'll watch for next time: _________
```

## Garden-Based Error Examples

The garden naturally produces errors that serve as teaching moments:

| Garden Error | Academic Connection | Restore Response |
|-------------|--------------------|-----------------|
| Seeds planted too deep | Measurement, following instructions | "These seeds need to be planted 1/4 inch deep. What happened here? How can we fix it?" |
| Overwatering | Volume, plant biology | "Too much water! What do plants actually need? How much is the right amount?" |
| Plants not growing | Scientific method, variables | "Our hypothesis didn't work out. What variables might have caused this? How can we test?" |
| Pest damage | Ecology, problem-solving | "Something happened to our plants. Let's investigate -- this is a real science mystery." |
| Wrong plant spacing | Measurement, fractions | "These are too close together. Let's measure the spacing and figure out the pattern." |
| Harvest too early/late | Time, observation, data | "We miscalculated the harvest date. What data can we look at to get closer next time?" |

## Key Principle

The Restore phase is never punitive. Errors are treated as diagnostic information that reveals what the student's brain is currently working on. The goal is not to eliminate errors but to build the metacognitive capacity to detect, analyze, and learn from them independently.
