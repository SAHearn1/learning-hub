# Appendix F: Standards Crosswalk

## Overview

This crosswalk maps FG2G curriculum activities to state and national standards across content areas. The dual-purpose design of the curriculum means that most garden-based activities align with multiple standards simultaneously.

| Measuring plant height | MGSE1.MD.1-2 | Order objects by length; measure using non-standard units |
| Garden bed area (tiles) | MGSE2.MD.1-4 | Measure length in standard units |

## CASEL Social-Emotional Learning Competencies

| CASEL Competency | FG2G Alignment | Assessment Method |
|-----------------|----------------|-------------------|
| **Self-Awareness** | Root phase: regulation self-assessment, growth journaling | Regulation level accuracy, journal entries |
| **Self-Management** | Regulate phase: self-regulation strategy selection and deployment | Regulation progression tracking, strategy use frequency |
| **Social Awareness** | Reconnect phase: community connections, cultural gardening, empathy | Peer interaction observations, community project participation |
| **Relationship Skills** | All phases: peer partnerships, collaborative garden work, mentoring | Collaboration rubric, peer feedback |
| **Responsible Decision-Making** | Reflect phase: TRACE protocol, reasoning moves; Restore phase: error analysis | TRACE protocol proficiency, reasoning move deployment |
