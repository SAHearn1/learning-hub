# Professional Development Session Plans

## Overview

The FG2G Professional Development program consists of six core modules delivered across the training year. Each module follows a consistent structure that mirrors the 5Rs framework — beginning with grounding (Root), moving through engagement and practice (Regulate, Reflect, Restore), and culminating in application and connection (Reconnect). This intentional design ensures educators experience the pedagogy they will facilitate.

## Module Structure Template

Every PD session follows this arc:

```
┌─────────────────────────────────────────────────┐
│  ROOT (15 min)                                  │
│  Garden-based opening, regulation check-in      │
├─────────────────────────────────────────────────┤
│  REGULATE (20 min)                              │
│  Community building, norms review, co-regulation│
├─────────────────────────────────────────────────┤
│  REFLECT (60-90 min)                            │
│  Core content, inquiry, practice                │
├─────────────────────────────────────────────────┤
│  RESTORE (30 min)                               │
│  Application planning, troubleshooting          │
├─────────────────────────────────────────────────┤
│  RECONNECT (15 min)                             │
│  Commitment statements, peer connections        │
└─────────────────────────────────────────────────┘
```

## Module 1: Foundations of Trauma-Informed Garden Education

**Duration:** 6 hours (full day)
**Delivery:** In-person with garden access
**Prerequisites:** None

### Learning Objectives

By the end of this module, educators will:
- Articulate the prevalence and educational impact of ACEs
- Describe the neurobiology of trauma and its implications for learning
- Experience garden-based grounding activities as a participant
- Identify connections between therapeutic horticulture and trauma recovery

### Session Plan

| Time | Activity | Materials | 5Rs Phase |
|---|---|---|---|
| 8:00-8:30 | Garden walk and sensory exploration | Garden space, journal | Root |
| 8:30-9:00 | Community agreements and regulation check-in | Regulation scale cards | Regulate |
| 9:00-10:00 | Presentation: ACEs research and educational impact | Slides, handout (Appendix B) | Reflect |
| 10:00-10:15 | Break | | |
| 10:15-11:15 | Interactive: Neurobiology of trauma — brain architecture activity | Brain model kits, diagram handouts | Reflect |
| 11:15-12:00 | Garden experience: Soil as foundation — testing and amending | Soil test kits, amendments | Reflect |
| 12:00-1:00 | Lunch | | |
| 1:00-1:45 | Presentation: Therapeutic horticulture evidence base | Research summary handout | Reflect |
| 1:45-2:45 | Small group discussion: Connecting research to practice | Discussion prompts, chart paper | Reflect |
| 2:45-3:30 | Application: Identifying trauma-informed opportunities in current practice | Planning template | Restore |
| 3:30-4:00 | Closing circle: Commitment statement and peer connections | Reflection cards | Reconnect |

### Facilitator Notes
- Begin with a personal vulnerability — share your own journey to understanding trauma's impact on learning
- Monitor educator regulation throughout; this content can activate personal trauma responses
- Provide opt-out opportunities for any activity without requiring explanation
- Have support resources available for educators who may be processing their own ACE experiences

## Module 2: The 5Rs Framework in Practice

**Duration:** 6 hours (full day)
**Delivery:** In-person with garden access
**Prerequisites:** Module 1

### Learning Objectives

By the end of this module, educators will:
- Describe each phase of the 5Rs framework with specific examples
- Experience each phase as a learner to develop empathetic facilitation
- Practice transitioning between phases based on regulation cues
- Design a mini-lesson incorporating at least three phases

### Session Plan

| Time | Activity | Materials | 5Rs Phase |
|---|---|---|---|
| 8:00-8:30 | Garden grounding: Seed planting ritual with intention setting | Seeds, pots, soil | Root |
| 8:30-9:00 | Regulation continuum activity: Where are you today? | Floor markers (0-100) | Regulate |
| 9:00-9:45 | Root phase deep dive: Safety signals and grounding techniques | Sensory materials, anchor charts | Reflect |
| 9:45-10:30 | Regulate phase deep dive: Co-regulation and self-regulation strategies | Strategy cards (Appendix D) | Reflect |
| 10:30-10:45 | Break — garden time | | |
| 10:45-11:30 | Reflect phase deep dive: TRACE protocol introduction and practice | TRACE cards (Appendix C) | Reflect |
| 11:30-12:15 | Restore phase deep dive: Error analysis and productive failure | Error analysis templates (Appendix E) | Reflect |
| 12:15-1:15 | Lunch — garden exploration | | |
| 1:15-2:00 | Reconnect phase deep dive: Community connection and purpose | Community mapping tools | Reflect |
| 2:00-3:00 | Workshop: Design a 5Rs mini-lesson for your grade band | Lesson planning template, standards docs | Restore |
| 3:00-3:45 | Gallery walk: Peer feedback on mini-lessons | Feedback forms, sticky notes | Restore |
| 3:45-4:00 | Closing: Garden harvest metaphor — what are you taking with you? | Reflection journal | Reconnect |

## Module 3: TRACE Protocol and Seven Reasoning Moves

**Duration:** 4 hours (half day)
**Delivery:** Hybrid (in-person preferred)
**Prerequisites:** Modules 1-2

### Learning Objectives

By the end of this module, educators will:
- Facilitate each step of the TRACE protocol with fluency
- Identify and prompt for each of the seven reasoning moves
- Differentiate TRACE facilitation by regulation level
- Practice responding to student reasoning in real-time

### Session Plan

| Time | Activity | Materials |
|---|---|---|
| 8:00-8:15 | Garden journal review and regulation check-in | Personal garden journals |
| 8:15-9:00 | TRACE protocol review and modeling with garden problem | Live plant specimens with problems to diagnose |
| 9:00-10:00 | Fishbowl practice: Facilitating TRACE with volunteer participants | TRACE reference cards, observation forms |
| 10:00-10:15 | Break | |
| 10:15-11:00 | Seven reasoning moves workshop: Identify, prompt, and assess each move | Reasoning moves cards, student work samples |
| 11:00-11:30 | Differentiation practice: Adapting TRACE for regulation levels 0-19, 20-39, 40-59, 60-79, 80-100 | Regulation scenario cards |
| 11:30-12:00 | Action planning: Implementing TRACE in your classroom this week | Planning template |

## Module 4: Regulation Assessment and Co-Regulation

**Duration:** 4 hours (half day)
**Delivery:** In-person required
**Prerequisites:** Modules 1-3

### Learning Objectives

By the end of this module, educators will:
- Use the Regulation Level Scale (0-100) with calibrated accuracy
- Demonstrate co-regulation techniques across all regulation tiers
- Practice non-anxious presence in simulated scenarios
- Develop a personal regulation maintenance plan

### Session Plan

| Time | Activity | Materials |
|---|---|---|
| 8:00-8:30 | Personal regulation assessment: Track your own patterns over 24 hours | Self-monitoring log |
| 8:30-9:30 | Calibration exercise: Video analysis of student regulation levels | Video clips, rating forms, Appendix B |
| 9:30-10:00 | Inter-rater reliability discussion: Aligning team assessments | Calibration data, group discussion |
| 10:00-10:15 | Break — garden regulation practice | |
| 10:15-11:00 | Co-regulation role play: Responding to each regulation tier | Scenario cards, co-regulation strategy menu |
| 11:00-11:30 | Non-anxious presence workshop: Somatic practices for educator regulation | Guided practice exercises |
| 11:30-12:00 | Personal regulation plan: Strategies for maintaining your own regulation | Planning template, peer accountability pairs |

## Module 6: Data, Documentation, and Continuous Improvement

**Duration:** 4 hours (half day)
**Delivery:** Virtual
**Prerequisites:** Modules 1-5 + minimum 1 semester implementation

### Learning Objectives

By the end of this module, educators will:
- Collect and analyze student regulation data using FG2G tools
- Document implementation fidelity and areas for growth
- Use the continuous improvement cycle to refine practice
- Prepare evidence for credentialing advancement

### Session Plan

| Time | Activity | Materials |
|---|---|---|
| 8:00-8:30 | Regulation check-in and garden update sharing | Photos from educator gardens |
| 8:30-9:30 | Data workshop: Reviewing student regulation trends, academic outcomes, and SEL measures | Data collection tools, sample reports |
| 9:30-10:15 | Fidelity self-assessment: Evaluating implementation against the FG2G framework | Fidelity rubric, evidence portfolio |
| 10:15-10:30 | Break | |
| 10:30-11:15 | Continuous improvement planning: Identifying refinements for next semester | PDSA cycle template |
| 11:15-11:45 | Credentialing pathway: Preparing your evidence portfolio for advancement | Credentialing requirements checklist |
| 11:45-12:00 | Closing reflection: Growth narrative from foundational training to now | Reflective writing prompt |

## Cross-Module Assessment

Educators maintain a professional growth portfolio throughout all six modules, documenting:
- Session reflections and garden journal entries
- Video recordings of 5Rs facilitation
- Student impact data and analysis
- Peer feedback and observation reports
- Personal regulation monitoring logs
- Action research findings (Tier 2+)
