# Data Collection Tools

## Overview

Effective trauma-informed, garden-based education requires robust data collection systems that capture the full complexity of student growth. The RootWork data collection framework measures academic progress, social-emotional development, and garden-based learning through integrated tools that minimize educator burden while maximizing instructional value. All data collection is purpose-driven: every data point should inform a decision about instruction, support, or program improvement.

Data collection in the RootWork model serves three audiences:

1. **Educators** -- to inform daily instruction, identify student needs, and document growth
2. **Students** -- to develop metacognitive awareness of their own learning and regulation
3. **Program Leaders** -- to evaluate implementation fidelity, measure outcomes, and report to stakeholders

## Academic Data Collection

### Standards Mastery Tracking

Standards mastery is tracked through the RootGuide platform's competency-based assessment system.

**How It Works:**
- Each lesson and assessment in the RootWork curriculum is tagged to specific Georgia Standards of Excellence (GSE), Common Core State Standards (CCSS), or Next Generation Science Standards (NGSS)
- As students complete lessons and assessments, mastery levels are automatically updated in the student's profile
- Mastery is reported on a four-level scale: Beginning, Developing, Proficient, Distinguished
- Educators can view mastery data at the individual student, group, or class level
- Trend lines show mastery progression over time, allowing educators to identify students who are accelerating, progressing steadily, or stalling

**Data Points Collected:**
- Standard identifier and description
- Date of assessment
- Mastery level achieved
- Assessment type (formative, summative, portfolio, performance-based)
- Number of attempts (for retake opportunities)
- Connection to 5Rs phase and TRACE engagement data

**Reporting Options:**
- Individual student mastery profile
- Class-level standards mastery heat map
- Grade-band mastery summary for administrative reporting
- Gap analysis identifying unmastered standards approaching assessment windows

### Reasoning Move Analytics

The TRACE protocol generates rich data about students' cognitive engagement and reasoning development.

**How It Works:**
- During AI tutor sessions, the RootGuide platform tracks which reasoning moves (Decompose, Compare, Question, Verify, Generalize, Transform, Connect) students employ
- Educators can also manually log reasoning moves observed during classroom instruction using the TRACE Observation Tool (available as a mobile app or printable checklist)
- The platform aggregates reasoning move data to show frequency, quality, and growth patterns

**Data Points Collected:**
- Reasoning move type
- Context (content area, lesson, 5Rs phase)
- Quality indicator (prompted by teacher/AI, student-initiated, student-to-student)
- Frequency per session
- Diversity of moves used (are students relying on one or two moves, or using the full range?)

**Reporting Options:**
- Individual student reasoning move profile (radar chart showing relative strength across all seven moves)
- Class-level reasoning move frequency distribution
- Growth over time in reasoning move diversity and quality
- Correlation between reasoning move engagement and standards mastery

### TRACE Engagement Metrics

Beyond reasoning moves, the TRACE protocol generates holistic engagement data.

**How It Works:**
- The AI tutor tracks student engagement signals during each TRACE phase: response time, response length, question-asking behavior, self-correction frequency, and extension attempts
- Engagement is scored on a composite index that combines cognitive engagement (reasoning depth) with affective engagement (persistence, curiosity, willingness to take risks)

**Data Points Collected:**
- Time spent in each TRACE phase (Think, Reason, Articulate, Check, Extend)
- Response latency (time between prompt and initial response)
- Response elaboration (word count, sentence complexity relative to grade band)
- Self-correction events (student revises initial response)
- Extension attempts (student applies learning beyond the prompted task)
- Help-seeking behavior (appropriate use of hints, strategy tools, or educator support)

**Reporting Options:**
- Individual TRACE engagement profile
- Engagement trends over time (weekly, monthly, quarterly)
- Engagement comparison across content areas
- Correlation between TRACE engagement and academic outcomes

## Social-Emotional Learning (SEL) Data Collection

### Regulation Tracking

Regulation data is central to the trauma-informed approach and is collected through multiple sources.

**Student Self-Report:**
- Regulation check-ins at the start and end of each platform session (slider scale from "very dysregulated" to "very regulated")
- Optional journaling about regulation experiences in the Growth Journal
- Weekly self-assessment using the RootWork Regulation Scale (age-appropriate versions for K-2, 3-5, 6-8, 9-12)

**AI Tutor Observations:**
- Response pattern analysis detecting potential dysregulation (increased errors, long pauses, disengagement, agitation indicators in text)
- Regulation strategy usage tracking (which strategies were offered, which were accepted, which were effective)
- Session outcomes when regulation strategies were deployed versus when they were not

**Educator Observation:**
- Daily regulation observation log (optional but recommended) -- educators note student regulation levels during key transitions
- Incident documentation when co-regulation intervention is needed
- Weekly class regulation summary (aggregate trends)

**Data Points Collected:**
- Self-reported regulation level (pre and post session)
- Regulation strategy used
- Effectiveness of strategy (student returned to window of tolerance: yes/no/partially)
- Time to return to regulated state
- Context of dysregulation event (trigger, setting, time of day)
- Educator co-regulation actions taken

**Reporting Options:**
- Individual student regulation trajectory over time
- Class-level regulation patterns (time of day, day of week, seasonal trends)
- Strategy effectiveness analysis (which strategies work best for which students)
- Correlation between regulation data and academic engagement
- Referral support: identification of students who may benefit from Tier 2 or Tier 3 regulation support

### Behavior Monitoring

Behavior data in the RootWork model focuses on understanding rather than punishment.

**How It Works:**
- Behavior events are documented using a trauma-informed framework that captures context, antecedent, behavior, and response (CABR model) rather than a punitive incident report
- Educators use the RootGuide Behavior Documentation Tool to log events quickly and connect them to regulation data
- The platform tracks positive behavioral events as well as challenging ones, maintaining a strengths-based perspective

**Data Points Collected:**
- Context: setting, time, activity, adults present
- Antecedent: what happened before the behavior (including potential triggers)
- Behavior: observable description (not interpretation)
- Response: educator response (co-regulation strategy used, environmental adjustment, referral)
- Outcome: student returned to regulated state, required additional support, or was removed from setting
- Follow-up: restorative conversation, family communication, support plan adjustment
- Positive events: instances of self-regulation, prosocial behavior, peer support, and growth mindset language

**Reporting Options:**
- Individual student behavior profile (frequency, trends, trigger patterns)
- Class-level behavior summary
- Antecedent analysis (identifying common triggers for classroom-level intervention)
- Positive behavior trends and celebrations
- Reduction in office discipline referrals (ODRs) compared to baseline

### SEL Competency Assessment

Broader SEL competencies are assessed through periodic surveys and performance tasks.

**Tools:**
- **RootWork SEL Survey:** A validated self-report survey administered three times per year (fall, winter, spring) measuring five domains: self-awareness, self-management, social awareness, relationship skills, and responsible decision-making. Aligned to CASEL competencies.
- **Educator SEL Rating Scale:** Educators complete a brief rating for each student three times per year, providing a second perspective on SEL development.
- **SEL Performance Tasks:** Embedded within the curriculum, these tasks assess SEL competencies in context (e.g., collaborative garden planning as a measure of relationship skills and responsible decision-making).

## Garden Data Collection

### Plant Growth Tracking

Garden data collection serves dual purposes: supporting scientific learning and documenting the living laboratory.

**How It Works:**
- Students record plant growth data using the RootGuide Garden Journal (digital or paper)
- Data collection is integrated into garden-based lessons as a scientific investigation skill
- The platform stores growth data and generates visualizations

**Data Points Collected:**
- Plant species and variety
- Planting date
- Germination date and rate
- Height measurements (weekly or biweekly)
- Leaf count, flower count, fruit count
- Harvest dates and yields (weight, volume)
- Observations of plant health (color, pest damage, disease signs)
- Growing conditions (soil type, sun exposure, watering schedule)

**Reporting Options:**
- Individual plant growth charts
- Comparative growth analysis (comparing varieties, conditions, or treatments)
- Class garden production summary
- Connection to science standards (life cycles, ecosystems, variables and controls)

### Biodiversity Surveys

Students conduct periodic biodiversity surveys in the school garden to document the ecosystem.

**How It Works:**
- Survey protocols are embedded in the science curriculum and appropriate to grade band
- K-2: Simple organism counts (insects, birds, worms)
- 3-5: Species identification and tally using field guides
- 6-8: Quadrat surveys, Simpson's Diversity Index calculations, population estimates
- 9-12: Full biodiversity assessments with statistical analysis

**Data Points Collected:**
- Survey date and time
- Weather conditions during survey
- Species identified (common name, scientific name for upper grades)
- Count or estimate per species
- Habitat observations
- Changes over time (seasonal patterns, year-over-year trends)

**Reporting Options:**
- Species inventory list
- Biodiversity index calculations
- Seasonal comparison charts
- Long-term ecosystem health trends
- Connection to NGSS performance expectations

### Weather Correlation

Weather data is collected to support scientific reasoning about garden outcomes.

**How It Works:**
- Students record daily weather observations as part of their garden journal
- The RootGuide platform can integrate with local weather station APIs for automated data collection
- Students analyze correlations between weather patterns and plant growth

**Data Points Collected:**
- Daily temperature (high, low, average)
- Precipitation (type and amount)
- Cloud cover and sun hours
- Wind speed and direction
- Humidity
- Frost dates
- Seasonal summary statistics

**Reporting Options:**
- Weather data tables and charts
- Correlation analysis between weather variables and plant growth
- Growing degree day calculations
- Seasonal weather summaries for garden planning
- Multi-year comparison for long-term garden programs

## Data Visualization and Reporting

### Visualization Tools

The RootGuide platform provides multiple visualization options for all data types:

- **Line Charts:** Growth over time (academic mastery, regulation, TRACE engagement)
- **Heat Maps:** Class-level standards mastery or engagement patterns
- **Radar Charts:** Individual student profiles across multiple competencies
- **Bar Charts:** Comparative data (groups, time periods, interventions)
- **Scatter Plots:** Correlation analysis (e.g., regulation and academic performance)
- **Dashboard Widgets:** Customizable educator dashboard with key metrics at a glance

### Report Types

| Report | Audience | Frequency | Content |
|--------|----------|-----------|---------|
| Student Progress Report | Families | Quarterly | Academic mastery, SEL growth, garden participation, portfolio highlights |
| Class Summary | Educator | Weekly/Monthly | Class-level trends in academic, SEL, and engagement data |
| IEP Progress Report | IEP Team | Per reporting period | Goal-specific progress data with RootWork alignment |
| MTSS Data Report | Student Support Team | As needed | Tiered support data including regulation tracking and intervention effectiveness |
| School Summary | Administrator | Quarterly | School-wide outcome data, implementation fidelity metrics, engagement analytics |
| District Summary | District Admin | Semester/Annual | Cross-school comparison, aggregate outcomes, equity analysis |
| Grant Report | Funders | Per grant requirements | Outcome data aligned to grant objectives and performance measures |

## Privacy and Security Protocols

### Data Classification

All data in the RootWork system is classified into three sensitivity levels:

| Level | Description | Examples | Access |
|-------|-------------|----------|--------|
| Standard | Non-sensitive educational data | Lesson completion, garden data, weather | Educator, student, parent |
| Sensitive | Personally identifiable educational records | Assessment scores, mastery levels, portfolio | Educator, student, parent, admin |
| Highly Sensitive | Regulation, behavior, and SEL data | Regulation tracking, behavior events, SEL survey responses | Educator, counselor, admin (role-restricted) |

### Access Controls

- Role-based access ensures that users only see data appropriate to their role
- Educators see data for their own students only
- Administrators see aggregate data with the option to drill down for specific students when needed
- Parents see only their own child's data
- Students see only their own data
- Counselors and support staff see data for students on their caseload

### Data Retention and Deletion

- Active student data is retained for the duration of enrollment plus one additional school year
- After the retention period, data is archived or deleted according to district data retention policy
- Parents may request data deletion at any time, subject to legal requirements
- De-identified aggregate data may be retained indefinitely for program evaluation and research

### Consent and Transparency

- Parents receive a clear, plain-language explanation of data collection practices at enrollment
- Active consent is required for students under 13 (COPPA compliance)
- Parents can opt out of specific data collection categories (e.g., regulation tracking) while maintaining access to academic features
- Annual data privacy notification is provided to all families

## Teacher Data Literacy Training

### Training Components

Effective data collection is only valuable if educators can interpret and act on the data. The RootWork PD program includes targeted data literacy training:

**Year 1 Data Literacy:**
- Navigating the RootGuide data dashboard
- Reading and interpreting student progress reports
- Using mastery data to identify instructional next steps
- Understanding regulation tracking and its classroom implications

**Year 2 Data Literacy:**
- Analyzing TRACE engagement data for instructional refinement
- Conducting data-informed student support conversations (PLCs, IEP meetings)
- Using comparative analytics to differentiate instruction
- Generating and interpreting custom reports

**Year 3 Data Literacy:**
- Leading data-informed PLCs
- Mentoring colleagues in data interpretation
- Using data for action research projects
- Presenting outcome data to stakeholders

### Data Use Protocols

To ensure that data serves students rather than sorting or labeling them, the RootWork model follows these data use protocols:

1. **Ask a question first.** Every data analysis session begins with a specific question about student learning or well-being. Data exploration without purpose can lead to deficit-based thinking.
2. **Look for strengths.** Before identifying gaps, identify what students can do and what strategies are working.
3. **Disaggregate with care.** Disaggregate data to identify equity gaps, but avoid using demographic data to reinforce stereotypes.
4. **Act on the data.** Every data analysis session ends with a specific instructional action step. Data without action is wasted time.
5. **Protect student dignity.** Never display individual student data publicly. Use data in private, confidential settings (IEP meetings, coaching debriefs, PLCs with clear confidentiality norms).
6. **Include student voice.** When possible, share data with students and invite their interpretation and input on next steps.
