# Data Collection Tools

## Overview

Effective FG2G implementation depends on systematic data collection across multiple domains — student regulation, academic progress, SEL development, garden outcomes, and program fidelity. The data collection tools within the RootGuide platform are designed to be efficient for educators, meaningful for decision-making, and respectful of student privacy. Every data point collected must serve a clear purpose: improving the experience and outcomes for students.

> *"In the garden, we test the soil before we plant, monitor moisture throughout the season, and evaluate the harvest at the end. Data collection in FG2G follows the same principle — measure what matters, when it matters, to grow what matters most."*

## Regulation Data Collection

### Daily Regulation Check-In Tool

The primary regulation data collection method is the daily check-in, adapted by grade band:

| Grade Band | Check-In Method | Data Captured | Frequency |
|---|---|---|---|
| K-2 | Emoji-based feelings selector (5 options mapped to regulation tiers) | Regulation tier, time of day, context | 2-3x daily |
| 3-5 | Visual slider scale (0-100) with optional word descriptor | Numeric score, descriptor, time, context | 2x daily |
| 6-8 | Numeric scale (0-100) with brief journal prompt | Numeric score, qualitative reflection, time | 1-2x daily |
| 9-12 | Self-directed numeric scale with pattern analysis | Numeric score, self-analysis, trends, time | 1x daily + self-initiated |

### Educator Observation Tool

Educators record regulation observations using a structured quick-entry interface:

| Field | Options | Purpose |
|---|---|---|
| Student | Select from class roster | Identify subject |
| Regulation level | 0-100 slider | Quantitative assessment |
| Context | Before/during/after instruction; transition; garden; free time | Contextual factor |
| Phase active | Root/Regulate/Reflect/Restore/Reconnect | 5Rs alignment |
| Triggers noted | Environmental, social, academic, sensory, unknown | Identify patterns |
| Response used | Co-regulation, sensory, movement, garden, peer, other | Track effective strategies |
| Outcome | Escalated, maintained, improved | Evaluate intervention |
| Time to entry | <30 seconds per observation | Minimize disruption to instruction |

### Regulation Trend Reports

The platform automatically generates trend analyses from collected data:

**Individual Student Report:**
- Daily regulation averages over time (line graph)
- Regulation by time of day (pattern identification)
- Regulation by context (which settings support/challenge regulation)
- Correlation with academic performance (dual-axis chart)
- Response to specific strategies (effectiveness analysis)

**Classroom Report:**
- Class-wide regulation averages and distribution
- Time-of-day patterns across the class
- Impact of specific activities on group regulation
- Students requiring additional support (flagged by persistent low scores)

**School/Program Report:**
- Aggregated regulation trends across classrooms
- Grade-band comparisons
- Seasonal patterns
- Year-over-year change analysis

## Academic Data Collection

### Formative Assessment Tools

| Tool | Description | Data Type | Frequency |
|---|---|---|---|
| TRACE Observation Checklist | Tracks student use of TRACE steps and reasoning moves | Categorical (observed/not observed) | During TRACE activities |
| Reasoning Moves Tracker | Records which of the 7 reasoning moves students demonstrate | Frequency count by move type | Weekly |
| Garden Investigation Rubric | Assesses quality of garden-based scientific inquiry | 4-point rubric scores | Per investigation |
| Dual-Purpose Activity Rating | Evaluates student engagement in both academic and SEL dimensions | Dual 1-5 scales | Per lesson |
| Exit Ticket Generator | Creates quick formative checks aligned to lesson objectives | Correct/partially correct/incorrect | Daily |

### Portfolio Assessment Tools

The digital portfolio system collects and organizes student work artifacts:

| Artifact Type | Collection Method | Assessment Criteria |
|---|---|---|
| Garden journal entries | Photo capture + written reflection | Observation quality, scientific accuracy, reflective depth |
| TRACE transcripts | AI tutor conversation logs (with consent) | Protocol engagement, reasoning quality, growth over time |
| Error analysis documents | Structured template submissions | Error identification accuracy, root cause depth, strategy quality |
| Project documentation | Multimedia uploads (photos, videos, documents) | Completeness, quality, connection to standards |
| Self-assessments | Guided reflection forms | Honesty, specificity, growth awareness |
| Peer feedback | Structured peer review submissions | Constructiveness, specificity, kindness |

## SEL Data Collection

### CASEL Competency Assessment

| CASEL Competency | FG2G Assessment Method | Data Source |
|---|---|---|
| Self-awareness | Regulation self-assessment accuracy (compared to educator rating) | Check-in data correlation |
| Self-management | Regulation recovery time; strategy usage; goal progress | Observation tool; portfolio |
| Social awareness | Peer interaction quality ratings; community engagement metrics | Educator observation; project data |
| Relationship skills | Co-regulation effectiveness; peer collaboration rubrics | Peer assessment; educator observation |
| Responsible decision-making | Error analysis quality; ethical reasoning in garden/community projects | Portfolio artifacts; project rubrics |

### Behavioral Data Integration

For students with behavioral support plans, FG2G data integrates with existing systems:

| Data Point | Integration |
|---|---|
| Office discipline referrals | Track pre/post FG2G implementation rates |
| Attendance | Correlate with regulation trends and garden activity participation |
| Suspension/expulsion | Monitor for reduction following FG2G implementation |
| Counselor referrals | Track type and frequency relative to FG2G participation |
| Positive behavioral notes | Document increases in positive behaviors and recognition |

## Program Fidelity Data

### Implementation Fidelity Checklist

Educators complete this self-assessment monthly:

| Domain | Indicator | Rating |
|---|---|---|
| 5Rs Implementation | All five phases addressed in each unit cycle | Always / Usually / Sometimes / Rarely |
| TRACE Protocol | TRACE facilitated at least 3 times per week | Always / Usually / Sometimes / Rarely |
| Garden Integration | Garden activities occur at least 2 times per week | Always / Usually / Sometimes / Rarely |
| Regulation Monitoring | Daily regulation check-ins completed | Always / Usually / Sometimes / Rarely |
| Dual-Purpose Design | Lessons address both academic and SEL objectives | Always / Usually / Sometimes / Rarely |
| Educator Regulation | Personal regulation practices maintained daily | Always / Usually / Sometimes / Rarely |
| Family Communication | Families receive FG2G updates at least monthly | Always / Usually / Sometimes / Rarely |

## Data Use Protocols

### Decision-Making Framework

| Data Pattern | Suggested Response |
|---|---|
| Individual student regulation declining | Schedule student conference; review strategies; consult with support team |
| Class-wide regulation drops at specific time | Adjust schedule; add Root phase activity before that time period |
| Academic growth stalling despite high regulation | Review instructional strategies; increase TRACE protocol usage |
| High regulation correlating with garden activities | Increase garden time; document for program evaluation |
| Low fidelity in specific domain | Access targeted PD; schedule coaching visit |

### Data Review Schedule

| Review Type | Frequency | Participants | Focus |
|---|---|---|---|
| Quick regulation scan | Daily | Individual educator | Identify students needing immediate support |
| Weekly data review | Weekly | Educator + PLC | Instructional adjustments and strategy planning |
| Monthly fidelity check | Monthly | Educator + coach | Implementation quality and support needs |
| Quarterly progress report | Quarterly | Team + administrator | Student outcomes and program effectiveness |
| Annual program evaluation | Annually | All stakeholders | Comprehensive review and planning |

## Privacy and Ethical Data Practices

### Guiding Principles

1. **Purpose limitation** — Data is collected only for the specific purpose of improving student outcomes
2. **Minimization** — Collect the minimum data needed for effective decision-making
3. **Transparency** — Students and families know what data is collected and why
4. **Access** — Families can view their child's data at any time through the Family Portal
5. **Security** — All data encrypted, access controlled, and handled in compliance with FERPA/COPPA
6. **Equity** — Data practices are reviewed for bias; data is never used to label or sort students
7. **Human judgment** — Data informs but never replaces educator professional judgment

### Data Governance

- **Data steward:** Building administrator responsible for data policies and access
- **Annual audit:** External review of data practices for compliance and ethical alignment
- **Incident response:** Documented protocol for data breaches or misuse
- **Retention schedule:** Student data retained for enrollment + 3 years, then anonymized or deleted
- **Research use:** Requires IRB approval and parental consent for any use beyond direct educational purpose
