# Agent Roster

AI work agents managed through n8n-MCP.

## Agents

| # | Agent | Role |
|---|-------|------|
| 1 | Research | Web research, data gathering, and source analysis |
| 2 | Document | Document creation, formatting, and management |
| 3 | Compliance | Regulatory checks, policy validation, and audit support |
| 4 | Content | Content writing, editing, and publishing |
| 5 | Financial | Financial analysis, reporting, and forecasting |
| 6 | Outreach | Communications, email campaigns, and stakeholder engagement |
| 7 | Scheduler | Calendar management, task scheduling, and deadline tracking |
| 8 | Verification | QA, fact-checking, and output validation |
| 9 | Media Production | Image, video, and multimedia content generation |

## Status

Each agent is configured as an n8n AI Agent node with dedicated system prompts, tool access, and workflow triggers.
