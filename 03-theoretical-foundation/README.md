# Theoretical Foundation - FG2G Curriculum

## Section Overview

This section provides the detailed research base for the From Garden to Growth curriculum. Each document examines a body of scholarship that directly informs the curriculum's design, with explicit connections to the 5Rs Framework and garden-based instructional practices.

## Contents

| Document | Description |
|----------|-------------|
| [ACEs and Education Impact](aces-and-education.md) | The Adverse Childhood Experiences study, its findings, and implications for educational practice |
| [Trauma-Informed Pedagogy](trauma-informed-pedagogy.md) | Principles and practices of trauma-informed teaching, including the six core principles |
| [Therapeutic Horticulture](therapeutic-horticulture.md) | Research on garden-based therapeutic interventions and their application to education |
| [Dual-Purpose Pedagogy](dual-purpose-pedagogy.md) | The FG2G model for integrating academic instruction with social-emotional development |
| [Literature Review](literature-review.md) | Comprehensive review of supporting research across all domains |

## Connection to the 5Rs Framework

Each theoretical tradition maps to specific phases of the framework:

- **ACEs Research** --> Understanding why students need the Root and Regulate phases
- **Trauma-Informed Pedagogy** --> Informing educator practices across all five phases
- **Therapeutic Horticulture** --> Validating the garden as the primary learning environment
- **Dual-Purpose Pedagogy** --> The integration model that unifies healing and learning
- **Literature Review** --> The evidence base supporting the entire framework
