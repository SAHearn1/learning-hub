## #178 — Register Stripe webhook endpoint in Stripe dashboard

**Status:** Manual step — requires Stripe dashboard access.

### Steps

1. Log in to [Stripe Dashboard](https://dashboard.stripe.com) → **Developers → Webhooks → Add endpoint**.
2. Endpoint URL: `https://app.rootwork.edu/api/stripe/webhook`
3. Select events:
   - `payment_intent.succeeded`
   - `invoice.payment_failed`
   - `customer.subscription.deleted`
   - `customer.subscription.updated`
4. Copy the **Signing secret** (starts with `whsec_`).
5. Set `STRIPE_WEBHOOK_SECRET=whsec_...` in the Vercel production environment variables.
6. Redeploy or restart the Vercel project for the env var to take effect.

### Validation

```bash
# Use the Stripe CLI to send a test event
stripe trigger payment_intent.succeeded \
  --override payment_intent:metadata.tenantId=<test-tenant-id>
# Watch Vercel logs for "Stripe webhook processed" message
```

## #192 — Fix E2E CI pipeline with Clerk test credentials

**Status:** Workflow and code changes implemented. Requires CI secret provisioning.

### Required GitHub Actions secrets

Configure these in **Settings → Secrets and variables → Actions** for the repository:

| Secret | Description |
|--------|-------------|
| `CLERK_PUBLISHABLE_KEY_TEST` | Clerk test-mode publishable key (`pk_test_...`) |
| `CLERK_SECRET_KEY_TEST` | Clerk test-mode secret key (`sk_test_...`) |
| `CLERK_FRONTEND_API_TEST` | Clerk frontend API URL for test mode |
| `E2E_CLERK_STUDENT_EMAIL` | Test student email address |
| `E2E_CLERK_STUDENT_PASSWORD` | Test student password |
| `E2E_CLERK_EDUCATOR_EMAIL` | Test educator email address |
| `E2E_CLERK_EDUCATOR_PASSWORD` | Test educator password |
| `E2E_CLERK_PARENT_EMAIL` | Test parent email address |
| `E2E_CLERK_PARENT_PASSWORD` | Test parent password |
| `E2E_CLERK_ADMIN_EMAIL` | Test admin email address |
| `E2E_CLERK_ADMIN_PASSWORD` | Test admin password |

### Obtaining Clerk test keys

1. Log in to [Clerk Dashboard](https://dashboard.clerk.com) → select application.
2. Navigate to **API Keys**.
3. Under **Test instance**, copy `Publishable key` and `Secret key`.
4. Create test user accounts in the Clerk test instance with the emails above.

### Validation

After secrets are provisioned, trigger the E2E workflow manually:

```
Actions → E2E Tests → Run workflow → branch: main
```

Expected: all Playwright specs pass; no "missing env vars" errors in setup step.
