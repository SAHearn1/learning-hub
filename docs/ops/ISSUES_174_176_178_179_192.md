## 2) Register Stripe webhook (Dashboard walkthrough)

1. Sign in to Stripe Dashboard for the project account.
2. Go to **Developers → Webhooks**.
3. Click **Add destination**.
4. Select **Webhook endpoint**.
5. Endpoint URL:
   - Production: `https://<your-domain>/api/stripe/webhook`
   - Preview/Test (optional): `https://<preview-domain>/api/stripe/webhook`
6. Choose events:
   - `checkout.session.completed`
   - `customer.subscription.created`
   - `customer.subscription.updated`
   - `customer.subscription.deleted`
   - `invoice.payment_failed`
7. Save endpoint.
8. Copy the generated signing secret (`whsec_...`).
9. Set signing secret in runtime environments:
   - Vercel: `STRIPE_WEBHOOK_SECRET`
   - GitHub Actions test env (if needed): `STRIPE_WEBHOOK_SECRET_TEST`
10. Send a test event from Stripe Dashboard and confirm your app returns `2xx`.
